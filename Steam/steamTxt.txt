[h3]Description[/h3]
A code mod that handles changes to UI, including sorting skipping intro and much more

[h3]Features[/h3]
- Skip the intro when starting up the game
- Sync filter between staff and applicant views
- Improve sorting for staff and applicant views based on Default (name) / Skill / Salary strategies
- Auto-continue last saved game on startup (default: false)
- Quick loading: skip main menu animations for faster navigation
